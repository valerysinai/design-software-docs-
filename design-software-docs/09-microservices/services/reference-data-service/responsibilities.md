# Responsabilidades del Reference Data Service

> Estado: 🟡 En progreso | Última actualización: 2026-06-25

## Objetivo

Centralizar la información institucional utilizada por los diferentes módulos del sistema.

---

## Responsabilidades

- Administrar regionales.
- Gestionar centros de formación.
- Mantener catálogos.
- Configurar parámetros generales.
- Publicar cambios relevantes mediante eventos.

---

## Límites del servicio

Este servicio no administra:

- Usuarios.
- Horarios.
- Ambientes.
- Documentos.
- Auditoría.

---
