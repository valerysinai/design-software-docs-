## Contenido

Esta sección documenta la arquitectura técnica del sistema Gestión de Horarios SENA, incluyendo los componentes principales, principios de diseño, despliegue, aspectos transversales y decisiones arquitectónicas adoptadas durante el proyecto.

La arquitectura está basada en una estrategia de microservicios alineada con los dominios funcionales definidos para la solución.
