# Onboarding Técnico

> Estado: 🟡 En progreso | Última actualización: 2026-06-26

## Objetivo

Facilitar la incorporación de nuevos integrantes técnicos al proyecto.

---

## Conocimientos recomendados

- Git.
- Docker.
- Java.
- Spring Boot.
- Maven.
- Bases de datos relacionales.
- Arquitectura de microservicios.

---

## Configuración inicial

Antes de comenzar:

- Clonar el repositorio.
- Configurar variables de entorno.
- Ejecutar Docker Compose.
- Verificar los microservicios.
- Ejecutar las pruebas.

---

## Documentación recomendada

Se recomienda revisar:

- Arquitectura.

- APIs.

---

## Flujo de trabajo

1. Crear una rama de desarrollo.
2. Implementar la funcionalidad.
3. Ejecutar pruebas.
4. Crear Pull Request.
5. Atender observaciones.
6. Integrar cambios.

---

## Buenas prácticas

- Seguir los estándares de codificación.
- Documentar nuevas funcionalidades.
- Mantener pruebas actualizadas.
- Realizar commits descriptivos.
- Participar en las revisiones de código.
