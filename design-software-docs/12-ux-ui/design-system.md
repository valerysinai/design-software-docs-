# Sistema de Diseño

> Estado: 🟡 En progreso | Última actualización: 2026-06-26
> Autor: Por definir | Equipo: Por definir

## Objetivo

Definir los lineamientos visuales y los componentes reutilizables para mantener una interfaz consistente en toda la plataforma.

---

## Identidad visual

El sistema debe utilizar una apariencia clara, moderna y consistente con la identidad institucional del SENA.

---

## Colores

| Elemento | Uso |
|----------|-----|
| Verde institucional | Acciones principales |
| Blanco | Fondo principal |
| Gris | Fondos secundarios |
| Azul | Información |
| Amarillo | Advertencias |
| Rojo | Errores |

---

## Tipografía

- Fuente principal para toda la aplicación.
- Tamaños consistentes para títulos, subtítulos y contenido.
- Alto contraste para mejorar la legibilidad.

---

## Componentes principales

- Botones.
- Campos de formulario.
- Tablas.
- Tarjetas.
- Menús.
- Barras de navegación.
- Ventanas modales.
- Alertas y notificaciones.

---

## Accesibilidad

La interfaz debe cumplir con las recomendaciones WCAG 2.1 nivel AA.

Se recomienda:

- Navegación mediante teclado.
- Contraste adecuado.
- Textos alternativos cuando corresponda.
- Diseño adaptable (Responsive).

---

## Principios de diseño

- Consistencia.
- Simplicidad.
- Claridad.
- Accesibilidad.
- Reutilización de componentes.
