## Contenido

Documenta el diseño de la experiencia de usuario (UX) y la interfaz gráfica (UI) de la plataforma, incluyendo el sistema de diseño, la navegación y los wireframes de las principales funcionalidades.

La documentación busca garantizar una experiencia consistente, accesible y fácil de utilizar para todos los perfiles de usuario del sistema.

## Objetivos

- Garantizar una experiencia de usuario consistente.
- Mantener una identidad visual uniforme.
- Facilitar la navegación entre módulos.
- Mejorar la accesibilidad y usabilidad.
- Servir como referencia para el desarrollo del Frontend.
